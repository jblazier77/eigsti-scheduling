## Security and save behavior

Session tokens are in HttpOnly, SameSite=Lax cookies. Cookies are Secure in production builds/environments; use the development server for local HTTP testing. Proxy refreshes sessions; pages and actions verify identity through Auth and an active live app profile. Server Actions apply their own role checks; showing a PM form does not grant its permissions. Direct API jobs route remains Bearer-token-only.

The job form uses controlled fields and one request UUID per form. An uncertain save preserves the details, prevents changing that payload, and offers retry with the same UUID. A confirmed save navigates to the returned job. The database command atomically creates job, default work and history. Actual dropped-connection/browser checks and simultaneous-user retry tests remain pending.
